# Workout Tracker

A Java console application for tracking workouts, exercises, and sets.

## Project Goal

This project is designed to practice:

- Object-Oriented Programming
- Java
- Software design
- Git workflow

## Planned Features

- Create workouts
- Add exercises
- Record sets
- View workout history
- Search workouts
- Track workout statistics

## Technologies

- Java
- Git
- GitHub
